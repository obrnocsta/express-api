# express-api

A simple API from scratch building with Express.js that use routes, query and path parameters, serve data, handle errors, and structure code effectively.

## 3 ways users can get data:

1. /api
2. /api/industry/ai
3. /api?has_mvp=true&is_seeking_funding=true

## We wil be studying:

- Creating a server
- Sending status code (200, 400, etc.)
- Setting headers
- Handling requests/responses
- Filtering data
- Extracting query/path params
